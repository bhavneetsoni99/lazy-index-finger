# Auto-next bookmarklets

Three small bookmarklets for Facebook and Instagram. No extension, no install, no permissions.

![demo](demo.gif)

| Bookmarklet | What it does |
| --- | --- |
| `fb-autonext.js` | Clicks Next photo on Facebook every 15s |
| `ig-autonext.js` | Clicks next on Instagram every 10s |
| `ig-enable-save.js` | Removes the overlay that blocks right-click on Instagram images |
| `rh-title-ticker.js` | Updates RobinHood title to display portfolio value |


## Install

1. Open the [install page](https://bhavneetsoni99.github.io/fb_insta_auto_next_and_save/)
2. Drag a button to your bookmarks bar

## Use

Open an album or post, click the bookmark. Click it again to stop the auto-next ones. Timers pause while the tab is in the background.

## Troubleshooting

Both sites change their markup often, and the Instagram selector relies on generated class names. If something breaks, [open an issue](../../issues).

## Editing

`*.js` files are the readable source. `bookmarklet.min.txt` and `index.html` hold the minified `javascript:` versions, so update them together.
